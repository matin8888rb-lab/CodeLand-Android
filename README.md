# CodeLand | کد‌لند

اپلیکیشن فارسی و رایگان آموزش برنامه‌نویسی برای اندروید.

## تصمیم‌های قطعی محصول
- پلتفرم: Android؛ خروجی APK
- زبان: فارسی، راست‌چین و فونت خوانا
- ظاهر: حرفه‌ای و مدرن
- دسترسی: رایگان
- اتصال: ترکیبی آنلاین و آفلاین
- معلم هوشمند: فعال‌سازی از طریق سرویس امن سمت سرور؛ کلید API هرگز داخل APK قرار نمی‌گیرد
- مسیر آموزشی نسخه اول: Python از مقدماتی تا پیشرفته

## قابلیت‌های هدف
- درس‌ها، مثال‌های توضیح‌دار، تمرین، آزمون و پروژه‌های مرحله‌ای
- ویرایشگر داخلی Python با رنگ‌آمیزی نحوی، اجرای کد، نمایش خروجی و خطا
- ذخیره و دسته‌بندی پروژه‌ها
- معلم هوشمند فارسی برای توضیح کد، راهنمایی و تحلیل خطا
- دسترسی آفلاین به محتوای دریافت‌شده و پیشرفت محلی
- همگام‌سازی آنلاین، پروفایل، XP، سطح، نشان و گزارش پیشرفت
- جست‌وجو، نشانک، واژه‌نامه، حالت روشن/تاریک و تنظیم اندازه متن

## ساختار مخزن
- `android/` برنامه اندروید
- `docs/` معماری، طراحی محصول و راهنمای توسعه
- `courses/` محتوای دوره‌ها
- `tests/` آزمون‌ها
- `.github/workflows/` ساخت خودکار APK

## امنیت و محدودیت‌های فنی
کد نوشته‌شده توسط کاربر باید در محیط محدود اجرا شود و نباید به فایل‌ها یا داده‌های خصوصی برنامه دسترسی آزاد داشته باشد. قابلیت هوش مصنوعی به backend نیاز دارد؛ کلید محرمانه در اپ قرار نمی‌گیرد. حالت آفلاین شامل درس‌ها و اجرای محلی است؛ قابلیت AI به اینترنت نیاز دارد.

## وضعیت انتشار
این مخزن محل توسعه نسخه یکپارچه است. APK فقط پس از ساخت موفق، بررسی خطاهای build و آزمون روی دستگاه قابل اعلام به‌عنوان نسخه قابل‌نصب است.
