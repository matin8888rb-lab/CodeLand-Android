# معماری کد‌لند

- رابط Android با Kotlin و Jetpack Compose، فارسی و راست‌چین.
- اجرای محلی Python 3.11 از طریق Chaquopy.
- درس‌های مقدماتی در نسخه پایه داخل برنامه تعریف شده‌اند.
- پیشرفت نسخه فعلی فقط در طول اجرای برنامه نگهداری می‌شود؛ Room/DataStore برای ذخیره پایدار لازم است.
- معلم هوشمند هنوز متصل نیست و به backend امن نیاز دارد. کلید API را هرگز داخل APK قرار ندهید.
- اجرای کد در این نسخه محیط آموزشی پایه است و sandbox امنیتی کامل محسوب نمی‌شود.
